📸 iPhone: Galeriye kaydetme

✅ Galeri modu açık. Gelen bir dosyada Kaydet → "Görüntüyü Kaydet" / "Videoyu Kaydet" deyin, doğrudan Fotoğraflar'a gider.

iPhone, fotoğrafı galeriye kaydetme menüsünü yalnızca güvenli bağlantıda açar. Bir kez, sadece dokunarak (yazı yazmadan) açılır:

  1. → İzin Ver → Kapat.
  2. Ayarlar uygulaması → en üstte "Profil İndirildi" → Yükle (şifre) → Yükle → Bitti.
  3. Ayarlar → Genel → Hakkında → Sertifika Güven Ayarları → ZETX DROP anahtarını açın → Devam.
  5. Açılan sayfada Paylaş → Ana Ekrana Ekle deyin (eski ZETX DROP simgesini silebilirsiniz).

Sertifika yalnızca ev/ofis ağındaki IP adresleri için geçerlidir; internet sitelerini etkilemez. Ayarlar → Genel → VPN ve Aygıt Yönetimi'nden istediğiniz an kaldırabilirsiniz.
